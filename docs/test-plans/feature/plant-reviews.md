# Test plan: feature/plant-reviews

## Summary

Adds plant reviews end-to-end: API list/create/delete for reviews, and a plant-page **Reviews** slot with list, signed-in write form (star rating + text), and a sign-in prompt for guests. Oracle: `docs/features/plant-reviews.md` and OpenAPI (`Review`, `ReviewList`, `ReviewCreate`); `docs/PRODUCT.md` accessibility baseline (WCAG 2.1 AA) still applies to the plant page.

## Assumed — ask

1. **Average rounding oracle:** Feature doc and OpenAPI say halves round **up** (5+4+5 → **4.7**). Implementation uses `Math.floor(...*10)/10` (would yield **4.6**). Confirm tests assert **4.7** and treat 4.6 as a finding.
2. **Delete ownership:** Docs say only the author can delete; anyone else gets “Review not found”. Implementation deletes any existing review for any authenticated user (no `userId` check). Confirm author-only is required — especially for seed rows with `userId: null`.
3. **Delete in UI:** Feature describes author-only delete, but the plant-page slot has no delete control. Confirm PR-01 API-only is enough for this branch (no Cypress delete UI).
4. **Post then list refresh:** Doc requires the new review to appear **right away**. Slot invalidates `['review', plantId]` while the query key is `['reviews', plantId]`. Confirm PR-10/PR-11 should fail and file a finding if the list does not update without a full reload.
5. **Keyboard stars:** Doc requires radio-like keyboard behavior; `StarRatingInput` is click-only today (no `tabIndex` / `aria-checked` / arrow handlers). Confirm PR-07/PR-12 assert the documented keyboard behavior.
6. **PRODUCT.md** does not mention reviews; **`docs/features/plant-reviews.md`** is the behavior oracle for this feature. Confirm.
